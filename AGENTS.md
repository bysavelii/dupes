# dupes

Правила этого проекта для агентов и людей. Процесс разработки задаёт Cyberzavod: этапы, роли и общие принципы приходят из его harness, здесь — только то, что относится к проекту. Файлы конкретного агента (например, `CLAUDE.md`) создаёт `cyberzavod sync` поверх этого файла.

## О проекте

- `dupes` — утилита командной строки: находит дубликаты файлов и похожие фото, показывает, сколько места освободится, и безопасно убирает лишнее в корзину, а не удаляет навсегда.
- Для кого: для всех, у кого кончается место на диске, — не только для разработчиков, поэтому сообщения и подсказки утилиты понятны без технической подготовки.
- Язык — Rust (stable). Инструменты: cargo (сборка, тесты, зависимости), clap (разбор аргументов командной строки), rustfmt (форматирование), clippy (линтер).
- Сообщения пользователю (вывод, ошибки, справка `--help`) и комментарии в коде — по-русски; идентификаторы (типы, функции, переменные, модули, имена флагов) — по-английски.
- Коммиты — по [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/): тип и область — по-английски, описание — по-русски. Пример: `feat(scan): искать дубликаты по содержимому файлов`.

## Команды

- Форматирование: `cargo fmt`.
- Проверки (`verification.commands` в `.cyberzavod/project.json`):
  - `make check` — `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`.

## Код и тесты

Правила кода и тестов проекта: по ним пишет исполнитель, проверяют тестировщик и ревьюер.

- Модульные тесты лежат рядом с кодом, в `#[cfg(test)] mod tests`; тесты командной строки — в `tests/`.
- Тесты создают файлы только во временных каталогах (`tempfile`) и не трогают файлы пользователя.
- Тест, который зависит от прав доступа, пропускает себя с пояснением, если права не действуют (запуск от root).
